- [ ] Confirm your course rules permit publishing a project description and self-authored diagrams.

- [ ] Do not upload starter_client.py, starter_server.py, or other course starter files unless permission is confirmed.
- [ ] Do not upload .env, API keys, database files, scraped content, screenshots with local paths, or ZIP submissions.
- [ ] Check the README and GIF for claims of a live demo (this one is explicitly illustrative).
- [ ] On GitHub, create a new repository and upload the CONTENTS of this folder, not the ZIP itself.
